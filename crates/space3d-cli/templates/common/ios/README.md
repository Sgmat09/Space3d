# iOS

The game ships as the `staticlib` of the `mobile/` crate, linked into a tiny Objective‑C app
(`main.m` calls the Rust `start_app()` generated by `space3d::main!`). The Xcode project is
described declaratively in `project.yml` for [XcodeGen](https://github.com/yonaskolb/XcodeGen),
so there is no hand-edited `.pbxproj` to merge.

## One-time setup

```sh
xcode-select --install                     # not enough on its own: install Xcode from the App Store
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
rustup target add aarch64-apple-ios aarch64-apple-ios-sim
brew install xcodegen
```

`space3d doctor --platforms ios` checks all of this.

## Build and run

```sh
space3d build --target ios --sim           # Rust lib for the simulator + xcodegen + xcodebuild
open -a Simulator
xcrun simctl install booted target/xcode/Build/Products/Debug-iphonesimulator/{{name}}.app
xcrun simctl launch booted {{ios_bundle_id}}
```

Or generate the project once and use Xcode:

```sh
cd ios && xcodegen generate && open {{name}}.xcodeproj
```

The *Build Rust library* pre-build phase runs `cargo build -p {{name}}-mobile` for the
selected SDK and configuration, so ⌘R always runs your latest Rust code. To run on a device,
select your team under *Signing & Capabilities* (bundle id `{{ios_bundle_id}}`).

The generated GitHub Actions workflow builds an unsigned `.ipa` the same way (XcodeGen +
`xcodebuild`); signing for TestFlight needs your certificates as repository secrets.
