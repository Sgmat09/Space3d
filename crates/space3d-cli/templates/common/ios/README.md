# iOS

Two ways to build the iOS app:

* **`space3d build --target ios --sim`** (simulator) / **`--target ios`** (devices): the game
  binary (`src/main.rs`, `space3d::main!`) bundled as `dist/ios/<target>/{{name}}.app` with a
  generated `Info.plist` — no Xcode project, no extra tools. Bundle id, name and orientations
  come from `[package.metadata.space3d.ios]` in `../Cargo.toml`.
* **`space3d build --target ios --sim --xcode`**: the Xcode project described by `project.yml`
  ([XcodeGen](https://github.com/yonaskolb/XcodeGen), so there is no hand-edited `.pbxproj` to
  merge). It links the `staticlib` of the `mobile/` crate into a tiny Objective‑C app (`main.m`
  calls the Rust `start_app()` generated by `space3d::main!`). Use it to run and debug on a
  device from Xcode and to manage signing, capabilities and icons there.

Both use the UIScene life cycle, which apps built with the iOS 27 SDK must adopt: the
`Info.plist` names the scene delegate class the engine registers (`Space3dSceneDelegate`).

## One-time setup

```sh
xcode-select --install                     # not enough on its own: install Xcode from the App Store
sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
xcodebuild -downloadPlatform iOS           # iOS SDK + simulator runtime, if Xcode lacks them
rustup target add aarch64-apple-ios aarch64-apple-ios-sim
brew install xcodegen                      # only for --xcode
```

`space3d doctor --platforms ios` checks all of this.

## Run in the simulator

```sh
space3d build --target ios --sim
xcrun simctl boot "iPhone 17"              # or open -a Simulator
xcrun simctl install booted dist/ios/aarch64-apple-ios-sim/{{name}}.app
xcrun simctl launch --console-pty booted {{ios_bundle_id}}   # logs in this terminal
```

Logs also go to the unified log: `xcrun simctl spawn booted log stream --predicate 'subsystem == "space3d"'`.

## Devices

`space3d build --target ios` writes an unsigned bundle; sign it with your Apple Development
identity and a provisioning profile for `{{ios_bundle_id}}` (the command prints the steps), or
generate the Xcode project once and let Xcode sign:

```sh
cd ios && xcodegen generate && open {{name}}.xcodeproj
```

The *Build Rust library* pre-build phase runs `cargo rustc -p {{name}}-mobile --lib
--crate-type staticlib` for the selected SDK and configuration, so ⌘R always runs your latest
Rust code (arm64 only: Apple silicon simulators and devices). Select your team under
*Signing & Capabilities* (bundle id `{{ios_bundle_id}}`).

The generated GitHub Actions workflow builds an unsigned `.ipa` the same way (XcodeGen +
`xcodebuild`); signing for TestFlight needs your certificates as repository secrets.
